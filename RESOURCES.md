# Curated DSA / CP Resources

The rule is simple: **one primary resource + one easier fallback**. Do not resource-hop.

## Foundations

- Big-O: our DSA notebook / notes first.
- Visual fallback: VisuAlgo.
- Practice: easy array problems on LeetCode.

## Core DSA

### Arrays / Hashing
Primary: LeetCode Explore / NeetCode.
Fallback: short visual explanations + guided problems.

### Two Pointers / Sliding Window
Primary: NeetCode pattern explanations + LeetCode.
Fallback: solve tiny examples manually before watching any solution.

### Binary Search
Primary: LeetCode binary-search study material.
Fallback: manually draw the shrinking search interval.

### Trees / Graphs
Primary: USACO Guide + CP-Algorithms.
Fallback: VisuAlgo for traversal visualization.

### Dynamic Programming
Primary: USACO Guide / CP-Algorithms.
Fallback: derive only three things first: **state, transition, base case**.

## Competitive Programming

- Codeforces: rating-based progression and contests.
- AtCoder: clean problem sets and contests.
- CP-Algorithms: reference when you need the formal algorithm.
- USACO Guide: curriculum and curated progression.

## ICPC

After core DSA is strong:

1. Solve regional problem sets.
2. Do timed team sessions.
3. Upsolve every unsolved problem.
4. Maintain an algorithm notebook.
5. Reattempt old problems without notes.

## Resource Policy

When Pavan says a topic feels too hard, add a simpler resource to this file and link it from the roadmap. Do not replace the difficult reference; use the easy resource as a bridge.
